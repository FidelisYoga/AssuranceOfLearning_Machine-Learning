# Student Exam Score Prediction

This project focuses on predicting student exam scores using a **Linear Regression** model.  
It covers the full machine learning workflow — from **data preprocessing**, **correlation analysis**, and **model training**, to **evaluation** and **interpretation** of key performance factors such as **study hours** and **attendance**.

---

## Overview
The goal of this project is to understand how academic behaviors influence exam outcomes and to build a predictive model capable of estimating students’ performance.

---

## Key Steps
- **Data Preprocessing:** Cleaned missing values, encoded categorical data, and handled outliers.  
- **Exploratory Analysis:** Examined correlations between study habits, attendance, and exam results.  
- **Model Training:** Built a Linear Regression model using training and testing splits.  
- **Evaluation:** Measured model performance using R², MSE, and MAE metrics.  
- **Interpretation:** Identified **study hours** and **attendance** as the strongest predictors of exam performance.

---

## Results
The Linear Regression model demonstrated good predictive accuracy, showing that consistent study time and attendance significantly impact student scores.
